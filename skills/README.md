# Agent skills used on this project

Short, generic versions of the instructions the coding agents followed. Each one is a `SKILL.md` that an agent
(Cursor, Codex, Claude Code, or any tool that reads skill folders) loads before the matching kind of work.
They are rewritten for publication: no accounts, machines or project-specific names.

| Skill | When it applies |
|---|---|
| [render-and-look](render-and-look/SKILL.md) | any change to the 3D scene |
| [prove-it-works](prove-it-works/SKILL.md) | before calling anything done |
| [statechart-tested-ui](statechart-tested-ui/SKILL.md) | interactive UI with modes (orbit, walk, pause) |
| [review-loop](review-loop/SKILL.md) | before merging a change |
| [no-nerf-optimization](no-nerf-optimization/SKILL.md) | making a heavy asset smaller or faster |
